# 单页制作流程

> 从“领到一页”到“线上可玩”。一页大约 30–90 分钟。
> 页面清单与归属见 `docs/页面清单.md`。
> 新手先看《新手配置教程》，把环境装好再回来。

## 一张图

```
领页 → 写需求单 → AI 生成 → 落盘 → 本地预览 → 可视化微调 → 自检 → 提交 → 线上验收 → 写变更
```

## 0. 领页

- 在页面清单里写上自己的名字，**一页同一时间只归一个人**。
- 确认这页属于哪条线：微界 / 新闻 / 聊天 / 结局。
- 确认跳转关系：从哪来、到哪去。

## 1. 写需求单

复制下面这段，填好再发给 AI：

```
【页面】weibo/post-02.html
【模式】flow
【作用】玩家在这里找到什么线索 / 完成什么动作
【参照】weibo/index.html 的页头、导航、卡片类名
【内容】
- 主贴：……
- 评论 5 条：……
【交互】
- 点击某元素 → 跳到哪个页面
- 加载时记录哪个旗标
【素材】
- 头像 assets/img/common/avatar-01.webp
【不要做】
- 不要引入外部库，不要写行内颜色，不要改页头结构
```

## 2. 给 AI 三样东西

1. `docs/项目约定.md` 的全文（或让 AI 先读这个文件）。
2. 上面那张需求单。
3. 一个同类参考页，例如 `weibo/index.html`。

开场白可以固定成：

> 先读 `docs/项目约定.md`，再以 `templates/page.html` 为骨架，生成下面这一页。只输出完整 HTML，不要省略。

## 3. 落盘

- 路径：`weibo/post-02.html`，英文小写 + 连字符。
- 图片放 `assets/img/<线>/`，先压缩成 WebP。
- 不要用中文文件名。

## 4. 本地预览

双击 `preview.cmd`。它会先同步样式，再开服务器，然后打开：

```
http://127.0.0.1:8000/
```

也可以手动：

```powershell
python -m http.server 8000
```

> 用 `127.0.0.1`，不要用 `localhost`。Windows 上 `localhost` 可能先走 IPv6，导致“拒绝连接”。

## 5. 可视化微调

把要改的 HTML 文件**拖到 `editor.cmd` 上**，松手。

- 浏览器会打开编辑器，端口 4317。
- 点选元素，改文字、改颜色、拖位置。
- 点保存，回到预览页刷新。

注意：

- **不要手改页面里的 `<style>` 块**，那是脚本管理的。
- 编辑器里改的单个元素样式只影响这一页；全站改色还是走 `assets/css`。
- 第一次打开会下载 GrapesJS，等一两分钟。

## 6. 自检

- [ ] 窗口拉到手机宽度，没有横向滚动条
- [ ] 所有链接都点一遍，没有 404
- [ ] 浏览器控制台没有红色报错
- [ ] 图片不模糊、不超过 300KB
- [ ] 交互元素有固定的 `data-*` 名字
- [ ] 刷新后进度还在

## 7. 提交

```powershell
git pull
git add .
git commit -m "[微界] 帖子详情：加时间线矛盾线索"
git push
```

提交信息格式：`[哪条线] 哪一页：做了什么`。

## 8. 线上验收

等 1 分钟，打开：

```
https://JasonJ578.github.io/find-your-name/
```

把刚改的页面再点一遍。线上和本地不一致，先强制刷新（`Ctrl+Shift+R`）。

## 9. 收工

- 负责人更新 `docs/交接-本地.md`。
- 在 `docs/变更记录.md` 末尾追加一条，写清修改人和内容。

## 工具表

| 用途 | 工具 | 怎么启动 |
|---|---|---|
| 写代码 / 改结构 | DSH 里的 AI | 打开 DSH，贴项目约定 |
| 本地预览 | `preview.cmd` | 双击 |
| 可视化编辑 | `editor.cmd` | 把 HTML 拖上去 |
| 样式同步 | `tools/inline-css.py` | `preview.cmd` 自动跑；改主题时手动 `--force` |
| 版本管理 | Git + GitHub | `git pull / add / commit / push` |
| 线上发布 | GitHub Pages | push 后自动 |

## 故障表

| 现象 | 原因 | 处理 |
|---|---|---|
| `ERR_CONNECTION_REFUSED` | 预览服务没开 | 双击 `preview.cmd`，用 `127.0.0.1` |
| 编辑器空白 | 编辑服务没起 | 重新拖一次文件到 `editor.cmd` |
| 页面没样式 | 忘了内联 | `python tools/inline-css.py` |
| 推送被拒绝 | 远程有你没有的提交 | 先 `git pull`，再 push |
| 冲突 | 两人改了同一页 | 不要硬合，找负责人 |
| `python` 不是命令 | 没装或没勾 PATH | 重装 Python，勾 Add to PATH |
| 端口 8000 被占用 | 之前的服务没关 | 关掉旧窗口，或换端口 |

## 时间参考

| 阶段 | 时间 |
|---|---|
| 写需求单 | 5–10 分钟 |
| AI 生成 | 1–3 分钟 |
| 预览 + 微调 | 15–40 分钟 |
| 自检 + 提交 | 5–10 分钟 |
| 合计 | 30–90 分钟 |
