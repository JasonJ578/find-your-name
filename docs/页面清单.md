## 怎么用

1. 领页：在负责人一栏写自己的名字，状态改成“进行中”。
2. 做完：状态改成“待验收”，在 `docs/变更记录.md` 追加一条。
3. 验收通过：状态改成“完成”。
4. 不要改别人负责的行，除非对方同意。
